# TodoListApp

Учебное консольное приложение на C# (.NET 10) для хранения списка задач. Создано в рамках практических работ по Git, GitHub и основам C#.

## Возможности

После ввода имени, фамилии и года рождения программа работает в бесконечном цикле и принимает команды:

- `help` - выводит список всех команд с кратким описанием;
- `profile` - выводит данные пользователя в формате `<Имя> <Фамилия>, <Год рождения>`;
- `add "текст задачи"` - добавляет новую задачу (статус "не сделано", текущая дата);
- `view` - выводит все задачи в формате `<индекс> <текст задачи> <сделано/не сделано> <дата>`;
- `done <номер>` - отмечает задачу выполненной и обновляет дату;
- `delete <номер>` - удаляет задачу, остальные сдвигаются на одну позицию влево;
- `update <номер> "новый текст"` - меняет текст задачи и обновляет дату;
- `exit` - завершает программу.

Номера задач считаются с единицы, как в выводе команды `view`.

## Как устроено хранение данных

Задачи хранятся в трёх массивах одинаковой длины: `todos` (тексты), `statuses` (выполнено или нет) и `dates` (дата создания или последнего изменения). Начальная длина массивов - 2. Если места не хватает, все три массива одновременно заменяются новыми, вдвое длиннее, и в них переписывается содержимое старых.

## Рефакторинг

- переменные имеют понятные имена;
- вместо "магических" значений используются константы (названия команд, начальный размер, коэффициент расширения);
- каждая команда и расширение массивов вынесены в отдельные методы.

## Запуск

Требуется установленный [.NET SDK 10.0](https://dotnet.microsoft.com/download).

Из командной строки, находясь в папке проекта (`TodoListApp`):

```
dotnet run
```

Из Visual Studio или JetBrains Rider: откройте файл `TodoListApp.csproj` и запустите проект (F5 / Run).

Введите имя: Иван
