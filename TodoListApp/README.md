# TodoListApp

Учебное консольное приложение на C# (.NET 10), созданное в рамках практической работы по Git и GitHub.

## Назначение

Программа запрашивает у пользователя имя, фамилию и год рождения, вычисляет возраст
(текущий год минус год рождения) и выводит сообщение в формате:

```
Добавлен пользователь <Имя> <Фамилия>, возраст - <возраст>
```

## Запуск

Требуется установленный [.NET SDK 10.0](https://dotnet.microsoft.com/download).

Из командной строки, находясь в папке проекта (`TodoListApp`):

```
dotnet run
```

Из Visual Studio или JetBrains Rider: откройте файл `TodoListApp.csproj` и запустите проект (F5 / Run).

## Пример

```
Введите имя: Иван
Введите фамилию: Иванов
Введите год рождения: 2005
Добавлен пользователь Иван Иванов, возраст - 21
```
